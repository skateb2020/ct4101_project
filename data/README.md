## Download Instructions
### Cloning Repo
When you clone the repo, the dataset will automatically be included in the data/ folder.
### Manual Downloading
If you would like to manually download this dataset from the Kaggle website, follow the following steps:
**Step 1:** Go to [https://www.kaggle.com/datasets/zayn1999/basketball-movement-biomechanics-dataset](https://www.kaggle.com/datasets/zayn1999/basketball-movement-biomechanics-dataset)
**Step 2:** Download the dataset by pressing the **Download** button and then pressing the **Download dataset as zip (14 kB)** selection
- will require a Kaggle account
**Step 3:** Extract the downloaded csv file into the data/ folder of this repo

## Preparation Instructions
No manual steps were taken to prepare this data prior to the preprocessing the data for the models.
